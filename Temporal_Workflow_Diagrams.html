Vehicle Registry Sync
Background refresh every 55 seconds — keeps vehicle data fresh without slowing live scans
Schedule: Every 55 seconds
Duration: ~10 seconds each run
Purpose: Decouple DB from live scan path
Priority: 8th (lowest)
⏰ SCHEDULE TRIGGER: EVERY 55 SECONDS
Runs in the background continuously. Separate from all live vehicle traffic.
▼
📡 STEP 1: Fetch Latest Vehicle Registry from Database
Query: all vehicles from Personnel table + car numbers from PersonnelExtend2
Retry: 3 times if DB is slow. Timeout: 30 seconds per attempt.
▼
Database query successful?
▼
✅ Query succeeded
▼
✅ STEP 2: Validate the Fetched Data
Check for malformed or incomplete records.
Count: total records · 2-wheelers · 4-wheelers
▼
💾 STEP 3: Update In-Memory Cache
Replace old cache with new data.
The live scan path now reads from this fresh cache instantly.
▼
🗄 STEP 4: Write to Backup Store
Write to local Redis or SQLite as fallback.
If server restarts, cache can be rebuilt from this immediately.
▼
📝 STEP 5: Log Sync Result
Record: timestamp · total records · duration · valid/invalid count
This data powers the "Cache last synced X seconds ago" shown on Health Check
